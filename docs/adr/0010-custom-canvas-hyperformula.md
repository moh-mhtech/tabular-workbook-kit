# Playground edits on the custom canvas and calculates with HyperFormula

Univer’s sheet UI did not give Excel-like table editing, so Playground mounts the Glide canvas and HyperFormula only. Univer remains in the kit as an unused adapter. Authoring language is still structured refs; HyperFormula receives compiled ranges because it does not understand them. A future host may choose the other adapter; this host does not.

This supersedes ADR 0002’s claim that HyperFormula is removed.
